# AdditionSubtractionAndTeenNumbersLab

**Proposed slot:** MK2 — provisional, confirm at build time per project convention.
**Grade:** K
**Standards covered:** K.OA.1 (represent addition/subtraction with objects, fingers, drawings, sounds, acting out, expressions, or equations), K.OA.2 (solve add/subtract word problems within 10, using objects or drawings), K.OA.3 (decompose numbers ≤10 into pairs in more than one way, e.g. with objects/drawings, record with a drawing or equation), K.OA.4 (for any number 1-9, find the number that makes 10), K.OA.5 (fluently add and subtract within 5), K.NBT.1 (compose/decompose numbers 11-19 into ten ones and some further ones, with objects/drawings, record with a drawing or equation).
**Relationship to existing labs:** No existing coverage — first lab for this content; assumes CountingAndCardinalityLab (MK1) as a prerequisite for raw counting/cardinality, but does not require it to be completed first unless the builder decides otherwise.
**Audience framing:** Built for a student seeing this content for the first time, regardless of the standard's posted grade level. Every addition/subtraction idea must be shown concretely (objects joining/separating, not bare "+"/"-" symbols introduced without a visual first) before any equation notation appears. K.NBT.1 is folded in as the lab's final unit because a teen number IS "10 and some more" — it's the natural payoff of the "make 10" unit, not a separate place-value topic.

## Units

### Unit 1: Putting Together and Taking Apart (Modeling Add/Subtract)
- **Goal:** You will be able to show addition as putting groups together and subtraction as taking a group apart, using objects, pictures, or your fingers.
- **Standard:** K.OA.1
- **Buckets:**
  - "Add to" scenario, result unknown (start with a group, add more, find the new total) — concrete objects
  - "Take from" scenario, result unknown (start with a group, remove some, find what's left) — concrete objects
  - Represent the same situation using fingers (no picture) — a distinct modality from objects/drawings
  - Represent the same situation using a simple equation/expression (e.g. 3 + 2 = 5) after the concrete version — the symbolic-translation step, not a standalone drill
- **Requires intro (CFU gate):** Yes — this is the first unit introducing addition/subtraction as concepts at all; common misconception is confusing which operation matches which action (treating "take away" language as sometimes meaning combine, or vice versa, when a word problem's wording is unfamiliar).
- **Memorization fact (periodic re-check candidate):** No — this unit teaches a representational skill (modeling an action), not a fact; a student who understands the concept can always re-derive which operation fits a new scenario.

### Unit 2: Solving Word Problems Within 10
- **Goal:** You will be able to solve simple story problems about adding or taking away, using numbers up to 10.
- **Standard:** K.OA.2
- **Buckets:**
  - Add To, result unknown ("3 birds, 2 more land, how many now?")
  - Take From, result unknown ("5 cookies, 2 are eaten, how many are left?")
  - Put Together/Take Apart, total unknown (two known parts combined into an unknown total — framed as "both groups together" rather than a sequential action)
  - Put Together/Take Apart, addend unknown ("5 crayons total, 2 are red, how many are blue?" — missing part, not missing total)
  - Compare, difference unknown ("Sam has 6, Mia has 4, how many more does Sam have?") — the hardest bucket, since it requires relating two separate quantities rather than acting on one
- **Requires intro (CFU gate):** No — this unit is extended, varied practice applying the add/subtract modeling already gated in Unit 1; no new core concept is introduced, just new problem-situation types layered onto the same operations.
- **Memorization fact (periodic re-check candidate):** No — solving a word problem is a reasoning/comprehension skill tied to the specific scenario each time, not a fixed fact.

### Unit 3: Breaking Numbers Apart (Decomposing ≤10)
- **Goal:** You will be able to break any number up to 10 into two smaller parts in more than one way.
- **Standard:** K.OA.3
- **Buckets:**
  - Decompose a small number (e.g. 4 or 5) — fewer possible part-pairs, easier to enumerate exhaustively
  - Decompose a larger number (e.g. 8, 9, or 10) — more possible part-pairs, harder to track without repeating a combination
  - Find a SECOND (or third) different decomposition of the same number after one is already given — explicitly tests "more than one way," not just any one correct split
  - Decompose into two EQUAL parts when the number is even (e.g. 6 = 3+3) — a special case students sometimes treat as impossible or skip
- **Requires intro (CFU gate):** Yes — the "more than one way" requirement is easy to under-teach if a student assumes one correct split is the whole task; common misconception is believing a number has exactly one decomposition and stopping there.
- **Memorization fact (periodic re-check candidate):** No — decompositions can always be re-derived by reasoning (or trial) about a given number; nothing here is meant to be memorized as a fixed fact.

### Unit 4: Making 10
- **Goal:** You will be able to figure out what number you need to add to any number 1-9 to make exactly 10.
- **Standard:** K.OA.4
- **Buckets:**
  - Find the partner for a small number (1, 2, 3) — large, easy-to-visualize complement
  - Find the partner for a number close to 10 (7, 8, 9) — small complement, easy to undercount
  - Find the partner for a "middle" number (4, 5, 6) — no proximity shortcut available
  - Given the completed pair (e.g. "6 and 4 make 10 — true or false?"), verify rather than produce — the reverse-direction check that confirms the fact is understood, not just pattern-completed
- **Requires intro (CFU gate):** Yes — "making 10" is a foundational mental-math anchor for all later addition strategies; common misconception is counting UP from 1 each time instead of recognizing/recalling the ten-complement, which this CFU should explicitly surface.
- **Memorization fact (periodic re-check candidate):** Yes — the ten-complements (1+9, 2+8, 3+7, 4+6, 5+5) are exactly the kind of small fixed fact set meant for long-term memorization and periodic re-checking, since instant recall (not re-derivation) is the actual goal of K.OA.4.

### Unit 5: Fast Facts Within 5
- **Goal:** You will be able to quickly add or subtract any two numbers when the answer is 5 or less, without having to count it out.
- **Standard:** K.OA.5
- **Buckets:**
  - Addition facts within 5 (all sums ≤5, e.g. 2+3, 1+4)
  - Subtraction facts within 5 (all differences from minuends ≤5, e.g. 5-2, 4-1)
  - "Doubles" within 5 (1+1, 2+2) — a distinct, often-memorized-first sub-pattern worth its own coverage
  - Missing-addend form within 5 (e.g. "2 + ? = 5") — same fact family, different unknown position, which is a genuinely different retrieval task than "2 + 3 = ?"
- **Requires intro (CFU gate):** No — this unit is fluency practice built directly on concepts already gated in Unit 1 (modeling add/subtract) and Unit 3 (decomposing small numbers); no new concept is introduced, only speed/automaticity on content already understood.
- **Memorization fact (periodic re-check candidate):** Yes — "fluently" in K.OA.5 specifically means memorized/automatic recall, not re-derivation each time, so this is a strong candidate for periodic re-checking to confirm facts stay instantly retrievable.

### Unit 6: Teen Numbers as Ten Plus More
- **Goal:** You will be able to see any number from 11 to 19 as "10 and some extra ones," and build or break apart teen numbers that way.
- **Standard:** K.NBT.1
- **Buckets:**
  - Compose a teen number from a ten-group plus extra ones (e.g. given 10 objects + 4 more, name it as 14) — building up
  - Decompose a given teen number into a ten-group and extra ones (e.g. given 17 objects, split into 10 + 7) — taking apart, the reverse direction
  - Teen numbers where the "extra ones" part equals the teens digit in a way that could be confused with the whole number read aloud (e.g. recognizing that "sixteen" means 10 + 6, not just repeating "16") — a vocabulary/notation check, not just a manipulative task
  - Record the composition/decomposition as a simple equation or drawing (e.g. 10 + 5 = 15) after the concrete version — the symbolic-translation step
- **Requires intro (CFU gate):** Yes — this is a new place-value concept (building on "make 10" from Unit 4 but now applied to a two-digit teen number); common misconception is treating the "1" in a teen numeral as just another single digit rather than understanding it represents a full ten-group.
- **Memorization fact (periodic re-check candidate):** No — this is a conceptual place-value understanding meant to be reasoned through each time (why 14 = 10 + 4), not a rote fact; it sets up later base-ten place value rather than being an isolated fact itself.

- Unit 4 (Making 10) and Unit 6 (Teen Numbers) are tightly coupled — the builder may find it natural for Unit 6's Explore to visually reuse/extend Unit 4's ten-frame-style diagram rather than building a new one from scratch; flagging as a likely `shared/diagrams` reuse opportunity, not a mandate.
- Unit 2's "Compare, difference unknown" bucket is the hardest problem-situation type at this grade level per the CCSS glossary note; the builder should confirm Practice doesn't quietly under-sample it relative to the easier Add To/Take From buckets.
